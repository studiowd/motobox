# Taller Cantón — Sitio Web Institucional (Proyecto Completo v2.0)

Sitio web institucional de alta gama para **Taller Cantón**, especializado en chapa y pintura, mecánica de motos y terminación estética.

## 🚀 Requisitos e Instalación

1. Node.js (versión 18 o superior recomendada).
2. Instalar dependencias:
   ```bash
   npm install
   ```
3. Ejecutar en entorno de desarrollo local:
   ```bash
   npm run dev
   ```
4. Generar build de producción:
   ```bash
   npm run build
   ```

## 🛠️ Stack Tecnológico y Rutas
- **Astro & TypeScript**
- **Tailwind CSS**
- **Rutas implementadas:** `/`, `/chapa-y-pintura/`, `/mecanica-de-motos/`, `/terminacion-estetica/`, `/trabajos/`, `/nosotros/`, `/contacto/`, `/privacidad/`.
